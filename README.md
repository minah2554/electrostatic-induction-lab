# ⚡ 정전기 유도 가상 실험실 (Electrostatic Induction Lab)

중학교 2학년 과학 「Ⅶ. 전기와 자기 - 전기를 띤 물체 근처에 가면 어떤 일이 생길까?」 수업을 위한 인터랙티브 가상 실험실 웹앱입니다.

금속(알루미늄 캔·쇠구슬)과 비금속(유리컵·스티로폼 컵)을 직접 선택해 대전체를 가까이 가져가며, 자유전자의 이동과 정전기 유도 현상을 눈으로 비교·관찰할 수 있습니다.

## 주요 기능

- 🔬 금속 / 비금속 물체 4종 선택 (알루미늄 캔, 쇠구슬, 유리컵, 스티로폼 컵)
- ⚡ (−)·(+)·중성 대전체 선택 및 직접 드래그로 거리 조절
- 🧤 마찰 횟수(전하량) 슬라이더로 인력의 세기 조절
- 🔍 실시간 관찰 가이드 · 📘 핵심 원리 요약 · ✏️ 형성평가 퀴즈 2문항
- 📱 모바일/태블릿/데스크톱 반응형 지원

## 기술 스택

순수 HTML + Tailwind CSS(CDN) + Vanilla JS(SVG)로 작성된 단일 파일(`index.html`) 웹앱입니다. 별도 빌드 과정 없이 브라우저에서 바로 실행됩니다.
